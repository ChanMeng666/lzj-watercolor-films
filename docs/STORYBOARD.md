# 劉仲敬思想 · 水彩短片三部曲 — 分鏡

全部畫面由代碼「畫」出：Python（numpy + OpenCV）程序化水彩引擎 → 分層位圖 → Canvas 視差合成 + WebGL 調色/轉場 → 無頭瀏覽器並行逐幀截圖 → ffmpeg 編碼 + 真實樂器採樣配樂。

**字幕約定**：帶書名號出處的是原文引語（已在語料中逐字核對）；不帶出處、用小號宋體的是概念標題（對框架的簡述，不冒充原話）。
